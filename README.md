# Application Run Examples on Toubkal

This repository provides example use cases showing how to run several scientific software packages on the Toubkal supercomputer.

Currently included:

- VASP
- Quantum ESPRESSO
- ORCA
- GROMACS
- CP2K
- ANSYS Fluent

Each directory contains the corresponding input files, Slurm submission scripts, and a short README explaining how to run the example.
